# internal/arch/sync_writes.txt: the machine-readable form of docs/design/01 §6.3
# (closed list of synchronous, same-transaction cross-module writes; 05 §2.4-3,
# 06 H-2). Format: <caller> -> <provider>.<Interface>.<Method>; * = every module.
# TestSyncWritesAreAllowed reads it as the allow-list for "// sync-write:" ports.
#
# Written once by BE-004; module tickets never edit this file (BE-001 R9). A new
# line needs 01 §6.3 first (orchestrator). On a conflict with 05 §2.4, 01 wins.

# Every module: audit log and file attachment in the caller's transaction.
*         -> audit.Logger.Log
*         -> files.Files.Attach

# 01 names three callers, and 01 wins (06 H-2, H-11).

students  -> consent.Recorder.Record
events    -> consent.Recorder.Record

# Targeted post publication (feed) and dispatch quota (outreach).

feed      -> outreach.Targeting.ScheduleDispatch

# Contact request and its acceptance (messaging).
messaging -> entitlements.Entitlements.Consume

# Club claim approval grants club_admin (directory).
directory -> orgs.OrgAdmin.GrantRole

# Order placement (orders).
orders    -> catalog.Offerings.Reserve
orders    -> entitlements.Entitlements.Grant

# Transfer match = payment capture (payments) and payout paid (ledger).
payments  -> orders.Orders.ApplyPayment

# BE-032 (rationale for 01 §6.3 in the BE-032 ticket's doc patch): the reverse of
# "Hedefli gönderi yayını" — deleting a company's targeted draft, or a moderator
# rejecting it in review, gives its targeted_post unit back in the same transaction
# (04 §2.7 deletePost "+ hak iadesi"; DECISIONS-LOG 2026-10-03), so a unit is never
# lost by a crash between the delete and the release nor released for a post that
# stays.
feed      -> entitlements.Entitlements.Release

# 06 H-49 (T-193; BE-049 writes this line, rationale for 01 §6.3 in the BE-049

# clears the request's export_file_id (7-day purge, account erasure), so the
# file never outlives its reference nor the reference its file.
